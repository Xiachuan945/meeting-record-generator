# meeting-record-generator
會議紀錄產生器

將 Word 會議逐字稿快速整理成正式的會議紀錄，並產生可下載的 Word 文件。

📌 工具簡介

本工具協助使用者將會議逐字稿整理成簡單、扼要、正式的會議紀錄，減少人工排版與重複整理的時間。

使用者只需上傳 Word 逐字稿，複製整理指令至 Claude（或其他 AI 工具），將整理完成的內容貼回網頁，即可產生格式統一的會議紀錄 Word 文件。

✨ 主要功能
Word 逐字稿讀取： 支援 .docx 格式。
AI 整理指令： 自動將逐字稿套入預設的會議紀錄整理 Prompt。
會議資料填寫： 可填寫開會時間、開會地點、主持人、記錄、出席者及散會時間。
日期星期自動帶入： 填寫民國年月日後，自動計算星期。
會議紀錄格式整理： 將整理完成的內容編排為正式文件。
Word 文件下載： 產生可下載的 .docx 會議紀錄。

📝 使用方式
開啟會議紀錄產生器網頁。
選擇 .docx 格式的會議逐字稿。
點選「讀取 Word」。
點選「複製 Prompt」，並將內容貼到 Claude。
將 Claude 整理完成的會議紀錄複製回網頁。
填寫會議時間、地點、主持人、記錄及出席者等資料。
點選「產生 Word」，下載會議紀錄文件。

📄 輸出格式

產生的會議紀錄包含：

壹、開會時間
貳、開會地點
參、主持人及記錄
肆、出席者
伍、報告、討論及決議事項
陸、散會

會議內容依照報告事項、討論事項及決議事項分類；沒有明確決議的內容，不應自行列為決議事項。

🛠️ 使用技術
HTML：網頁結構
CSS：頁面樣式與排版
JavaScript：檔案讀取、資料處理及文件產生
Mammoth.js：讀取 Word .docx 文字
docx.js：產生 Word .docx 文件
Claude：協助整理會議逐字稿
GitHub Pages：網頁部署與託管

🔒 隱私與注意事項
本工具使用瀏覽器端 JavaScript 讀取 Word 文件，並產生 Word 輸出檔案。
使用者將整理指令貼到 Claude 時，逐字稿內容會傳送至 Claude 服務。
請勿上傳未經授權外傳的機密文件、個人敏感資料或其他受限制的內容。
本工具目前沒有使用者登入、權限管理或雲端會議紀錄儲存功能。
網頁使用的外部 JavaScript 套件需透過 CDN 載入，使用時需要網路連線。

🚀 部署方式

本工具可使用 GitHub Pages 部署。

將檔案上傳至 GitHub Repository。
確認主要網頁檔案命名為 index.html。
進入 Repository 的 Settings → Pages。
在 Build and deployment 中選擇 Deploy from a branch。
選擇 main 分支及 /(root) 資料夾。
儲存設定，等待部署完成。

📌 工具定位

本工具為輔助會議紀錄整理的網頁工具，AI 產生的內容仍須由使用者確認，以確保會議決議、日期、人名等細節正確。
